## Архитектура проекта

Цель: кратко описать основные подсистемы, их роли и связи. Комментарии внутри кода ведутся на английском, но этот документ — на русском.

Высокоуровневые подсистемы
- Рендеринг (`renderer.js`): рисует фон, параллакс, платформы (pre-render), игрока, портал и частицы. Работает с камерой.
- Физика/состояние (`physics.js`): игровой стейт-машин, time-scale (пауза/замедление), обработка столкновений (через `player.updatePlayer`), респавн, конец уровня, очки.
- Игрок (`player.js`): состояние игрока, прыжки (двойной прыжок через модификатор), вращение, события приземления.
- Генератор уровня (`levelGenerator.js`): платформа→пробелы→платформа, безопасные расстояния на основе физики прыжка, коллекции и модификаторы, портал, параллакс-наборы.
- Камера (`camera.js`): цель — игрок или платформа респавна; плавное следование; защита от падения ниже последней безопасной платформы.
- Ввод (`input.js`): клавиатура/мышь/тач, автопрыжок (тач и удержание ЛКМ), пауза; жесты фуллскрина отключены.
- Аудио (`audio.js`, `audio/sfx.js`, `audio/music/proceduralMusic.js`): инициализация, транспорт Tone.js, звуки прыжка/смерти/победы, фон.
- UI (`ui.js`): меню (main/pause/level-end), HUD (очки/уровень/смерти), fade, баннер старта уровня.
- Коллекции (`collectibles.js`): типы, отрисовка, сбор и эффекты (магнит, double jump), сброс/реактивация.

Поток выполнения
1. `index.html` загружает `js/main.js` (ES module).
2. `main` инициализирует UI и Input, ресайзит канвас и запускает `requestAnimationFrame`.
3. При старте уровня: генерируется музыка, уровень (`generateLevel`), делается `preRenderLevel`, сбрасывается игрок, камера привязывается.
4. Цикл: `updatePhysics(dt)` → обновление видимых сущностей, игрока, частиц, портала; затем `draw(...)`.
5. События: смерть → частицы, панорамирование камеры к респавну, `finalizeRespawn`; вход в портал → стейт `levelEnding` → меню окончания.

Состояния игры (state machine)
- `mainMenu`: главный экран.
- `levelReady`: уровень сгенерирован, ждём первого прыжка (или автопрыжка) для старта.
- `playing`: активная игра.
- `pausing` → `paused` → `resuming`: пауза через плавный `timeScale`.
- `dead`: взрыв частиц; далее `panningToRespawn` и `finalizeRespawn()`.
- `enteringPortal`: анимация входа в портал → `levelEnding` → показ меню уровня.
- `levelEnd`: показ меню конца уровня.

Time scale
- Гладко интерполируется к `timeScaleTarget` (0..1). UI-паузы синхронизируются с размытиями и затемнением.

Камера
- Имеет смещение к игроку, сглаживание, независимую цель на время респавна; зажим по Y, чтобы не уезжать ниже безопасной платформы.

Процедурная генерация
- Длина уровня зависит от номера уровня; безопасные промежутки рассчитываются с учётом физики прыжка и текущей скорости.
- Коллекции сортируются по X; модификаторы ограничены первой половиной уровня и влияют на вертикальное распределение пикселей.

Рендеринг
- Предварительно отрисованные платформы на отдельный `canvas` ускоряют основной кадр.
- Параллакс-слои с разной скоростью; деревья/кусты колышутся.

Очки и статистика
- `levelStats`: время старта, собранные пиксели, смерти; `totalScore` — суммарный счёт; бонус за нулевые смерти.

Модули и зависимости
- `main` связывает `ui`, `input`, `audio`, `physics`, `renderer`, `camera`, `levelGenerator`, `player`.

Скорость
- Горизонтальная скорость игрока нормализована относительно ширины канваса: `setPlayerSpeedNormalized(baseSpeed, canvasWidth)`.

Полноэкранный режим
- Переключение только через кнопки UI в меню паузы и конце уровня.
